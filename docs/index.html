BanglaMemo

A Handwritten Bangla Receipt Dataset
for OCR-Based Expense Tracking

Digital Image Processing • June 2026

The Problem

"Millions of retail transactions in Bangladesh rely on handwritten paper receipts — yet no OCR system can read them."

  • Clothing bazaars, grocery stores, and street markets still use handwritten receipts
  • Receipts feature messy, informal Bangla handwriting
  • Mixed scripts: Bangla + English + Bangla numerals
  • No existing dataset captures this real-world messiness

The Gap in Existing Datasets

Dataset Type Size Limitation

BanglaMemo is the first dataset specifically targeting handwritten Bangla receipts from informal retail settings.

Automated Mislabel Detection

The Problem

9 receipts had store names (e.g., "মুফ্তি টেক্স") labeled as Item_Name instead of Store_Name.

This caused item crops to include the entire store header — up to 60% extra image area.

The Fix

  • Detect Item_Name boxes in the top 20% of the image
  • Check if gap to the next item cluster > 15%
  • Reclassify as Store_Name automatically
  • 9 receipts corrected, 0 false positives

Outlier Detection Heuristic

if bbox.y < 0.20 × image_height:
  # In top 20% zone
  gap = next_item.y - bbox.bottom
  if gap > 0.15 × image_height:
    # Spatial gap confirms mislabel
    reclassify → Store_Name

Data Augmentation

9 Augmentation Techniques

☀️ Brightness

±20% variation — different lighting

🔲 Contrast

±20% variation — camera exposure

↻ Rotation

±3° — tilted receipt photos

📡 Gaussian Noise

σ 5–15 — camera sensor noise

🔍 Gaussian Blur

0.5–1.5px radius — slight defocus

📐 Perspective Warp

±2% — angled photography

📸 JPEG Compression

Quality 50–85 — compression artifacts

📄 Paper Crumpling

Elastic sine-wave deformation — folded/creased paper

🖊️ Ink Smudging

Selective directional motion blur on ink regions

Each image gets 4 augmented copies with random combinations of 2–3 techniques. Applied to training set only.

Augmentation Results

Original

+ Ink Smudge

+ Paper Crumple + Perspective

+ Noise + Rotation

Text remains fully readable in all variants — the OCR learns to handle degradation, not guess at destroyed text.
